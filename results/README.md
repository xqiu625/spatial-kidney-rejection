Marker scores are signed, background-corrected expression scores. Marker-profile frequencies are frequencies of spot groups, not cell proportions. Condition and subtype summaries contain one row per biopsy; they have no patient-level significance tests.

`spatial_lr_all.csv` includes every tested combination and the complete BH family, including zero-edge combinations with score=0 and p=1. `spatial_lr_fdr.csv` is its adjusted screen. `n_edges` is a directed edge count for that sample/ordered cluster pair. The same edge can contribute to different LR gene pairs, so rows must not be summed as independent physical interactions.

Neighborhood enrichment Z-scores are separate within-biopsy calculations; undefined Z-scores are missing. Co-occurrence distances are in image pixels. Sample identity strongly tracks the expression embedding, so the UMAP is not evidence of a generalizable disease signature.

[Legacy outputs](legacy_20260724) are retained for traceability and are not valid substitutes for these rerun outputs. Raw data, executed notebooks and full H5AD checkpoints remain in the local run directory and are not committed.
