# Generated Figures

This directory contains visualizations generated by the analysis pipeline.

## Expected Outputs

After running the notebooks, you will find:

| Figure | Notebook | Description |
|--------|----------|-------------|
| `qc_metrics.png` | 01 | QC violin plots and distributions |
| `spatial_clusters.png` | 02 | Leiden clusters on tissue coordinates |
| `umap_clusters.png` | 02 | UMAP colored by cluster |
| `celltype_spatial.png` | 03 | Cell type scores on tissue |
| `celltype_heatmap.png` | 03 | Cell type marker expression |
| `nhood_enrichment.png` | 04 | Neighborhood enrichment heatmap |
| `co_occurrence.png` | 04 | Cell type co-occurrence patterns |
| `niche_spatial.png` | 04 | Tissue niches visualization |
| `lr_heatmap_all.png` | 05 | L-R interaction scores heatmap |
| `lr_heatmap_comparison.png` | 05 | Control vs rejection L-R changes |
| `communication_network.png` | 05 | Cell-cell communication network |
| `top_LR_pairs.png` | 05 | Top ligand-receptor interactions |

## Reproducing Figures

Run notebooks 01-05 sequentially to generate all figures:

```bash
jupyter notebook notebooks/
```
