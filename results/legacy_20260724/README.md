# Superseded analysis — do not use as validated results

These files preserve outputs from commit `72856f7` and earlier. They were moved here during the analysis-validity correction.

They include marker fold changes computed from scaled expression, uncalibrated marker “proportions”, graphs that did not separate slides, unadjusted LR significance, raw-count LR scores without spatial constraints, and spot-level condition tests with insufficient biological replication. The overview image describes that older implementation.

These artifacts are retained only for traceability. They are not outputs of the corrected notebooks and must not be mixed with the new run tables or figures. Fresh runs write into `runs/<name>/`, with parameters and versions in `run.json`.
